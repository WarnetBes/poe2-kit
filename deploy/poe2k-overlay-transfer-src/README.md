# PoE2 Kit — перенос на игровой ПК (192.168.0.200)

Пакет для запуска Windows-оверлея PoE2 Kit на компьютере с игрой.

## Что это
Прозрачный оверлей поверх окна Path of Exile 2:
- Хоткей **Ctrl+F1** — читает предмет из буфера (в игре `Ctrl+C`) и показывает оценку цены.
- **Ctrl+F3** — импорт билда: PoB share-код / ссылка (pobb.in, poe.ninja) / .build JSON.
  Ссылка на персонажа poe.ninja (`/poe2/profile/.../character/...`) + Ctrl+F3 включает
  автосинхронизацию: эквип персонажа сверяется со слотами билда автоматически.
- **Ctrl+F2** — панель-шопинг-лист билда: цены слотов, бюджет, что уже собрано,
  и что сейчас надето в каждом слоте («носите: …»).
- **Ctrl+F4** — контекст прокачки (зона, подсказки) из лога игры.
- **Ctrl+F5** — режим перемещения оверлея.
- Окно само подгоняет высоту под контент панели.
- По умолчанию берётся актуальная лига (из poe2scout), цены — poe.ninja / poe2scout / trade2.
- Клики «проходят сквозь» окно оверлея в игру.
- Окно привязывается к правому верхнему углу окна PoE2, прячется, когда игра свёрнута.

## Требования на игровом ПК
- **Node.js LTS** (>= 20): https://nodejs.org — единственная обязательная зависимость.
- **Git не нужен** — всё в этом пакете.
- C++ build tools обычно **не нужны** (`koffi` и `electron` ставятся готовыми бинарниками);
  понадобятся только если `npm ci` упадёт на нативном модуле (см. подсказки в bat).

## Запуск
1. Распакуйте архив в папку вне игры, например `C:\poe2k-overlay`.
2. Запустите **`start-overlay.bat`** двойным кликом.
3. Первый запуск: установятся зависимости и соберётся оверлей (несколько минут).
4. Запустите игру; наведите на предмет, `Ctrl+C`, затем `Ctrl+F1` — рядом с правым верхним
   углом окна игры появится панель с оценкой цены.
5. Повторные запуски — мгновенно (зависимости уже установлены).

## Обновление уже установленной копии
Если оверлей уже стоит на игровом ПК — **удалите старую папку с исходниками**
(кроме `node_modules`, её можно перенести в новую папку ради скорости) и распакуйте
новый zip целиком: старые исходники (старые хоткеи Ctrl+Alt+…) не обновятся сами.

## Дополнительно в пакете (по желанию)
- Веб-дашборд: `npm run dev -w @poe2-kit/web` → http://localhost:5173 (курсы, прайс-чек, прокачка, импорт билда).
- MCP-сервер для ИИ: `npm run start -w @poe2-kit/mcp` (32 инструмента `poe2_*`).

## Как перенести на игровой ПК
- Расшаренная папка: `net use X: \\192.168.0.200\...` — или наоборот, с игрового ПК:
  `\\<этот-ПК>\<шара>\poe2k-overlay-transfer.zip`.
- Или скопируйте архив флешкой/по сети любым способом — это обычный zip без установки.

## Примечания
- Оверлей работает локально и ходит в бесплатные публичные API напрямую, без ключей.
- Антивирус может спросить разрешение на Electron при первом запуске — это норма.
- В окне терминала видны логи запросов; закрыв терминал, вы закроете оверлей.
