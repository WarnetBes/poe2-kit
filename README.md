# poe2-kit

Единый помощник для Path of Exile 2: гид по прокачке, AI-советы, универсальная торговля, анализ билдов и прайс-чек предметов. Одно ядро (@poe2-kit/core) для трёх форм: веб-приложение, Windows-оверлей (Electron) и MCP-сервер для ИИ. Цены и торговля — только с бесплатных публичных API (poe.ninja, poe2scout, официальный trade2).
