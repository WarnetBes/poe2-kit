# Как помочь PoE2 Kit (отзывы, идеи, данные о предметах)

Спасибо за интерес! Проект жив на энтузиазме: любая обратная связь — через
issues: **https://sourcecraft.dev/volkovpartilaholin/poe2-kit/issues**

## Отзывы и рекомендации по улучшению

Самая ценная помощь — создать issue (русский/английский):

- **«Что понравилось / что неудобно»** — любой сценарий: прайс-чек, оверлей,
  веб, MCP-инструменты, гайд.
- **Баг:** что делали, что ожидали, что получилось (приложите дайджест
  диагностики оверлея, если дело в нём: Ctrl+F6 → «Диагностика»).
- **Идея фичи:** опишите сценарий «в игре я хочу …».

## Помочь kit «узнавать предметы» (opt-in, анонимно)

Самая хрупкая часть PoE2-инструментов — соответствие «текст мода ↔ stat-id
trade2»: почти каждый патч GGG меняет схему, и прайс-чек раров ломается. Вы
можете поделиться знанием просто пользуясь kit:

1. **Включите журнал обучения** (по умолчанию ВЫКЛЮЧЕН):
   - PowerShell: `setx POE2K_LEARN 1` (затем перезапустить kit), для сессии:
     `$env:POE2K_LEARN='1'`.
   - Пользуемся как обычно: прайс-чек предметов (оверлей Ctrl+Alt+Space, веб,
     MCP) пишет **локально** в `~/.poe2-kit/learn/items.jsonl`.
2. **Сформируйте вклад:** `npm run contribute-items -w @poe2-kit/core` —
   создаст `poe2-items-contribution-<дата>.json`.
3. **Проверьте содержимое** — это открытый JSON. Внутри только данные о
   предметах: редкость, база, моды, stat-id, лига. **Никаких имён персонажей,
   аккаунтов и прочих сведений о вас** (полный список — в
   [SECURITY.md](SECURITY.md)).
4. **Приложите файл к issue** с заголовком «Item data contribution».

Мейнтейнер прогоняет файл через строгий валидатор
(`packages/core/merge-contributions.mjs`), данные попадают в офлайн-библиотеку
kit (`packages/core/data/game/learned/`) и выходят с новым релизом. Схема
стат-trade2 сломается патчем — а у kit будет последнее известное соответствие,
и прайс-чек продолжит работать.

Лицензия вкладов данных: те же условия, что и у проекта ([MIT](LICENSE)).

## Правки кода от сообщества

Запросы на слияние сразу в `main` не принимаются: перечислите предлагаемые
изменения в issue (можно с патчем в тексте). Мейнтейнер применяет правки
вручную, глядя дифф — это защищает пользователей от внедрения вредоносного
кода (см. [SECURITY.md](SECURITY.md)).

## Запуск из исходников

```bash
npm install
npm run build        # ядро (@poe2-kit/core)
npm run test -w @poe2-kit/core   # офлайн-смок
```

Веб (`npm run web`), оверлей (`npm run overlay`), MCP (`npm run mcp`) —
см. [README.md](README.md).
