# Поэ2 Kit — деплой на Beget (volkovqi.beget.tech)

В этом пакете готовый PoE2 Kit для размещения на хостинге Beget как **отдельной
страницы-вкладки** по адресу:

    https://volkovqi.beget.tech/poe2kit/

## Что внутри

- `poe2kit/` — готовое веб-приложение (обязательно собрать, см. ниже).
  - `index.html`
  - `assets/` — JS/CSS-бандлы
  - `proxy/` — PHP-прокси для обхода CORS-блокировок API:
    - `proxy.php` — сам прокси-скрипт
    - `.htaccess` — перенаправление `/proxy/...` на `proxy.php`
- `ВКЛАДКА-сниппет.html` — код для добавления вкладки-ссылки в меню вашего сайта.
- Дисклеймер уже встроен в приложение (кнопка «О проекте · Дисклеймер» внизу).

## Почему нужен прокси

Цены/лиги берутся из poe.ninja, poe2scout.com и официального trade API. Эти сервисы
не отдают браузеру заголовки CORS, поэтому без серверного прокси браузер блокирует
запросы. Прокси (`proxy.php`) работает на сервере Beget (PHP есть всегда), поэтому
всё работает даже на обычном (не Node) хостинге.

## ЭТАП 1 — Собрать приложение

На своей машине, в корне репозитория `poe2-kit`:

    npm run build:deploy -w @poe2-kit/web

Результат появится в `apps/web/deploy-dist/`. Это и есть содержимое каталога `poe2kit/`.

## ЭТАП 2 — Собрать каталог poe2kit

Скопируйте в один каталог `poe2kit/`:

```
poe2kit/
  index.html          <- из deploy-dist/
  assets/             <- из deploy-dist/assets/
  proxy/
    proxy.php         <- из deploy/proxy.php
    .htaccess         <- из deploy/proxy.htaccess (сам файл переименовать в .htaccess)
```

## ЭТАП 3 — Залить на Beget

1. В панели Beget откройте «Файловый менеджер» или подключитесь по FTP/SFTP.
2. Откройте корень сайта (обычно `public_html/` или `volkovqi.beget.tech/`).
3. Загрузите папку `poe2kit/` целиком в корень.
4. Проверьте: `https://volkovqi.beget.tech/poe2kit/` должен открываться.

> Если видна пустая страница или ошибка доступа к файлу — проверьте права на файлы
> (см. раздел «Права на файлы» ниже) и что включён mod_rewrite (по умолчанию на Beget активен).

## ЭТАП 3.5 — Права на файлы (важно!)

После загрузки проверьте, что у файлов и папок корректные права. Если их нет,
браузер отдаст «403 Forbidden» или пустую страницу.

**Рекомендуемые права:**
- Папки (включая `poe2kit/`, `poe2kit/assets/`, `poe2kit/proxy/`) → `755`
- Файлы (`index.html`, `.js`, `.css`, `proxy.php`, `.htaccess`) → `644`
- `proxy.php` → обычно `644` достаточно (скрипт PHP выполняется самим сервером,
  отдельного права «выполнения» не требует)

**Как выставить в файловом менеджере Beget:**
1. Выделите папку/файл и выберите **«Изменить права»** (или «Права доступа» / CHMOD).
2. Выставьте числа: для папок `755`, для файлов `644`.
3. Удобнее всего выставить права на всю папку `poe2kit/` сразу, включив
   «Применить рекурсивно ко вложенным файлам/папкам».

> Примечание: если вы загружаете **ZIP и распаковываете** его в файловом менеджере
> Beget, права обычно выставляются автоматически. Проверка нужна только если
> на странице ошибка доступа — тогда просто пройдитесь по файлам и выставьте 644/755.

**Как проверить права через FTP** (если вы подключаетесь клиентом, например FileZilla):
- ПКМ по папке/файлу → **Permissions / Права** → впишите число и нажмите OK.
- В FileZilla есть чекбокс «Apply to all files and folders» — удобно для всей папки разом.

## ЭТАП 4 — Добавить вкладку на сайт

Откройте свой сайт и в его навигационном меню добавьте вкладку-ссылку:

```html
<a href="/poe2kit/" title="PoE2 Kit — помощник для Path of Exile 2">PoE2 Kit</a>
```

Используйте код из `ВКЛАДКА-сниппет.html` (там есть стилизованный вариант).

## Проверка прокси

Откройте в браузере:

    https://volkovqi.beget.tech/poe2kit/proxy/scout/poe2/Leagues

Должен прийти JSON со списком лиг. Если вместо этого ошибка 500 — откройте панель
Beget → раздел журнала ошибок PHP и пришлите последнюю строку.
