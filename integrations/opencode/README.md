# PoE2 Kit — интеграция с OpenCode (агенты-ассистенты)

Здесь живёт **каноническая копия экосистемы агентов PoE2 Kit** для OpenCode.
Она встраивает кит в OpenCode как полноценного ассистента: обычный вопрос по
PoE2 попадает в диспетчера, диспетчер маршрутизирует в профильного subagent-а,
все цифры — только из MCP-тулов `poe2_*`.

```
integrations/opencode/
├── agents/
│   ├── poe2-kit.md      # primary-диспетчер: билды→builder, рынок→trader
│   ├── poe2-builder.md  # subagent: сборка/верификация билдов (PoB-оракул)
│   └── poe2-trader.md   # subagent: цены/продажа/валюты (рынок trade2)
├── skill/SKILL.md       # скилл-шорткат poe2-kit — режим кита в любой сессии
└── install-agent.mjs    # установщик (idempotent, защита чужих файлов)
└── README.md            # этот файл
```

## Как это встраивается (почему не ломает кит)

Слои развязаны:

| Слой | Что даёт | Где живёт |
|---|---|---|
| MCP-сервер `poe2-kit` | 79 тулов `poe2_*` (данные) | `apps/mcp`, конфиг `mcp.poe2-kit` |
| Агенты (эта папка) | поведение/дисциплина/маршрутизация | `~/.config/opencode/agents/` (или `.opencode/agents/`) |
| Скилл-шорткат | вход в режим кита из любой сессии | `~/.config/opencode/skills/poe2-kit/` |

Агенты — только markdown-конфиг OpenCode; они **не трогают ни код, ни dist,
ни датасеты кита**. MCP-сервер не знает об их существовании. Поэтому
«встроить агента в кит» = опубликовать его определение в репозитории кита и
доставить в конфиг OpenCode установщиком — а не переписать MCP-сервер.

Рабочий процесс агентов строится поверх публичного API тулов. Изменения тулов
(алиасы №622, счётчик) в агентах отражаются точечно, по факту, не превентивно.

## Установка

Из корня репозитория poe2-kit:

```bash
# глобально (доступно во всех проектах/сессиях OpenCode)
node integrations/opencode/install-agent.mjs

# только в текущий проект (.opencode/agents/)
node integrations/opencode/install-agent.mjs --project

# + дописать MCP-запись poe2-kit в opencode.json (если её нет)
node integrations/opencode/install-agent.mjs --with-mcp

# посмотреть план без записи
node integrations/opencode/install-agent.mjs --dry-run --with-mcp
```

Поведение установщика (проверено sandbox- прогонами A–D, 27.10.2026):

- **Идемпотентен**: повторный запуск обновляет только изменившиеся файлы,
  иначе «уже актуально», exit 0.
- **Не разрушает чужое**: файл цели без маркера `poe2-kit:managed` считается
  чужим → не перезаписывается, exit 2 с подсказкой `--force`. С `--force`
  печатает прежнее содержимое перед перезаписью.
- **MCP-конфиг бережёт**: существующий `opencode.json` не переписывает целиком
  — делает бэкап `opencode.json.bak-<stamp>` и дописывает только ключ
  `mcp["poe2-kit"]`; уже подключённый сервер (совпавшая команда) не трогает.
- **Горячий путь**: OpenCode V2 подхватывает агентов без рестарта сервиса
  (форс — `/reload`). Рестарт нужен только для свежего dist MCP-тулов.

## Проверка после установки

```bash
opencode agent list        # должны быть poe2-kit (primary), poe2-builder, poe2-trader
```

Живой прогон (матрица владельца, №636): редкий предмет с Ctrl+C → trader;
0.5-новинка → честное «данных нет»; уник + «собери билд и прикинь бюджет» →
builder→trader со склейкой.

## Правки и обновления

1. Правьте **только файлы этой папки** (канон), коммитьте в репозиторий.
2. Раскатка на машине: `node integrations/opencode/install-agent.mjs`
   (обновит копии; свои кастомные правки в `~/.config/...` перед этим сохраните —
   installer их не удалит молча, но и не сохранит за вас).
3. Файлы-носители вне git (личное окружение) остаются резервной копией:
   старые `~/.config/opencode/agents/poe2-*.md` до первой установки — оригиналы
   сессий №619/№633–638.

## Известные границы

- Скилл-шорткат `poe2-kit` конфликтует по имени с… ничем (имена скиллов
  уникальны), но если у вас уже есть свой `skills/poe2-kit` — установщик
  покажет КОНФЛИКТ и не перезапишет.
- Диспетчер запрещает себе shell и правит файлы только с confirmation (ask) —
  это осознанно: ассистент по игре не должен иметь доступа к произвольным
  командам.
- Агенты требуют подключённый MCP-сервер kита; без него они честно сообщают
  «дефект среды» вместо имитации тулов.
