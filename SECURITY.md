# Безопасность PoE2 Kit

Коротко: **контрибьюции сообщества — только данные, никогда код**. Пользователи
не могут сломать kit или внедрить в него вредоносный код.

## Как данные пользователей попадают в репозиторий

Единственный путь данных от пользователей в репозиторий:

1. У пользователя **opt-in** журнал (выключен по умолчанию, `POE2K_LEARN=1`
   включает, см. [CONTRIBUTING.md](CONTRIBUTING.md)) — локальный файл
   `~/.poe2-kit/learn/items.jsonl`. Никуда автоматически не отправляется.
2. Команда `npm run contribute-items -w @poe2-kit/core` формирует JSON-дайджест.
3. Пользователь **сам** прикладывает файл к issue на SourceCraft.
4. Мейнтейнер прогоняет файл через строгий валидатор
   `packages/core/merge-contributions.mjs` и **вручную** просматривает
   `git diff` перед коммитом.

## Гарантии

- **Валидатор — единственная дверь.** Белый список ключей, точные типы,
  лимиты длин (имя ≤128, мод ≤256 символов), лимит объёма (≤5000 записей),
  stat-id только по строгому формату `^(explicit|implicit|crafted|enchant|pseudo|fractured)\.stat_…`,
  отклонение любых управляющих символов. Всё, что не проходит схему, — отбрасывается
  с ошибкой, файл целиком не принимается.
- **Датасеты — только данные.** Библиотеки в `packages/core/data/game/learned/`
  — JSON-файлы, читаются через `JSON.parse` и никогда не исполняются
  (нет `eval`, нет `require` пользовательских данных, нет плагинов).
- **Пользователи не пишут в репозиторий напрямую.** Ветка `main` принимает
  коммиты только от мейнтейнера; наружу выходят issues и обсуждения.
- **Кодовые правки от сообщества** — только через issue/запрос с описанием и
  патчем; применение — вручную мейнтейнером с полным чтением диффа.
- **Network:** kit ходит только на публичные API (poe.ninja, poe2scout,
  trade2 pathofexile.com) и никогда не отправляет данные пользователя на
  сторонние серверы — журнал обучения лежит локально до тех пор, пока сам
  пользователь не решит сделать вклад.

## Приватность (что именно пишется в журнал)

Только структура проверенного предмета: время, лига, редкость, имя и базовый
тип **предмета**, item class, item level, требуемый уровень, тексты явных
модов, сматченные stat-id trade2. **Не пишется:** имя персонажа, аккаунт,
IGN, любые сведения о пользователе. См. `packages/core/src/learnlog.ts`.

## Как сообщить об уязвимости

Создайте приватное обращение к владельцу репозитория
(`volkovpartilaholin` на https://git.sourcecraft.dev/volkovpartilaholin/poe2-kit)
или issue с пометкой «security». Не публикуйте эксплойты до исправления.
