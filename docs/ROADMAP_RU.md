## 1. Контекст (кратко)

PoE2 Kit — монорепозиторий: `packages/core` (данные + trade/parse), `apps/overlay`
(Electron поверх игры), `apps/mcp` (55 `poe2_*`-туров для ИИ-агентов), `apps/web` (дашборд).
Целевой сценарий: SSF-прокачка (Invoker Ice Strike CI) + повседневный прайс-чек
на русском клиенте. Развитие шло от билд-инструментов к живому игровому ассистенту.

## 5. Неприкосновенные принципы (для всех будущих задач)

1. **Privacy по умолчанию:** clipboard-watch / learn-log — только opt-in (уже так).
2. **RU-клиент — гражданин первого класса:** каждый прайс-чек обязан работать на русском (уроки №75: poe2db-«и», префиксы).
3. **Только публичные API GGG/poe.ninja/poe2scout/poe2db, UA + дисклеймер** (GGG-комплаенс №68), никаких secrets в коде.
4. **Nested-core деплой = dist + data + package.json** (урок №73).
5. **Доказательства:** любое имя API/факта — из Sources/доки, не по памяти.
6. **Live-smoke свежести перед релизом** (после A4 — обязательный шаг playbook).

## 6. Definition of Done для задач ТЗ

- Код прошёл build всех затронутых workspace (`npm run build -w @poe2-kit/<app>`)
- Если фиксятся живые точки — деплой на шару + верификация хэшем
- Журналируется: бумага в `cubes/cube5_log.md`, куб-2 обновлён
- CHANGELOG при пользовательских изменениях; версия bumped по playbook релиза
- Для датасет-задач: live-проверка свежести (`poe2_data_freshness`)
