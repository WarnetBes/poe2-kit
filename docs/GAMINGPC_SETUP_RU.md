# Запуск PoE2 Kit на игровом ПК (друга) — пошаговая инструкция

> Цель: полный сетап из шары `\\192.168.0.200\OpenCodeProjectsF\poe2-kit`
> (v1.0.31): MCP-сервер, оверлей и web-приложение с вкладкой «🧮 PoB-оракул»
> (живой движок PoB2 в персист-сессии). Актуально: 11.10.2026, релиз 1.0.31.
>
> Требования: Windows 10/11, Node.js LTS (проверка: `node -v`; если нет —
> https://nodejs.org), ~3 ГБ на диск, доступ к шаре. Всё офлайн после пункта 4,
> кроме качания клона PoB2 (один раз, ~400 МБ).

---

## 0. Куда смотреть если что-то не работает

| Симптом | Причина | Что делать |
|---|---|---|
| Тулы отвечают `available:false … сетап` | рантайм оракула не найден | пункты 3–5 ниже |
| Вкладка PoB-оракул: «Оракул недоступен (HTTP 503)» с hint | нет POE2K_POB2_SRC / рантайма | пункты 3–5, hint в интерфейсе повторяет шаги |
| Веб не открывается | не запущен serve-dist | пункт 6 |
| `node` не находится | Node.js не установлен или не в PATH | https://nodejs.org, перезапустить терминал |

## 1. Скопировать кит с шары (один раз)

```bat
xcopy \\192.168.0.200\OpenCodeProjectsF\poe2-kit C:\poe2-kit\ /E /I /Y
```

Рекомендуемый дом — `C:\poe2-kit` (без пробелов и кириллицы в пути — LuaJIT
чувствителен). Дальше везде `<KIT>` = этот каталог, примеры пишут `C:\poe2-kit`.

## 2. Зависимости

Из шары переносится `node_modules` production-граней. Если что-то не заводится —
доставить локально:

```bat
cd /d C:\poe2-kit
npm install --omit=dev
```

Живой интернет нужен только для этого шага и пункта 4.

## 3. Рантайм оракула (LuaJIT) — уже в шаре, проверить

```bat
dir C:\poe2-kit\oracle\bin
```

Должны лежать `luajit.exe` + `lua51.dll`. SHA256-гейт ставился
`node oracle\setup-headless.mjs` один раз на машине-доноре; на игровом ПК
достаточно файлов. Если их нет:

```bat
cd /d C:\poe2-kit
node oracle\setup-headless.mjs
```

(скомпирует и проверит SHA256; живой интернет нужен).

## 4. Клон движка PoB2 (единственный «тяжёлый» шаг)

Оракулу нужен НЕПАТЧЕННЫЙ клон PathOfBuilding-PoE2 (движок грузится штатным
HeadlessWrapper, патчей апстрима нет — поэтому можно брать официальный релиз):

```bat
git clone https://github.com/PathOfBuildingCommunity/PathOfBuilding-PoE2 C:\TestPE\PathOfBuilding-PoE2
```

Если `git` нет — zip с релиза: https://github.com/PathOfBuildingCommunity/PathOfBuilding-PoE2/releases
(тег v0.23.1 — тот же пин, что в CI), распаковать, например, в
`C:\TestPE\PathOfBuilding-PoE2`. Важен именно подкаталог `src` внутри.

## 5. Переменная окружения POE2K_POB2_SRC

Указывает на **`...\src`** клона (не на корень!):

```bat
setx POE2K_POB2_SRC "C:\TestPE\PathOfBuilding-PoE2\src"
```

`setx` пишет в постоянное окружение — после него ЗАКРЫТЬ и открыть терминал
заново (текущее окно переменную не увидит). Проверка в новом окне:

```bat
echo %POE2K_POB2_SRC%
```

## 6. Web-сервер с PoB-оракулом

```bat
cd /d C:\poe2-kit\apps\web
node serve-dist.mjs
```

Откроется на `http://localhost:5173` (порт можно сменить: первым аргументом,
например `node serve-dist.mjs 5199`). Первый boot движка — ~2–3 с один раз,
дальше пересчёты за миллисекунды.

### Вкладка «🧮 PoB-оракул» (раздел «Билд»)

1. Вставь PoB share-код (AA…) или XML билда (или нажми «Из поля "Импорт
   билда"», если код уже вставлен там) → **Загрузить билд**.
2. Отметь сценарии: Босс / Пиннакл+Хаос75 / Uber / уровни 92-95-100 — или впиши
   свой уровень 1–100 → **Прогнать матрицу**.
3. Читай Δ% к baseline: как меняются Life/DPS/EHP против боссов и на уровнях.
   Сценарии изолированы (CAS-откат), порядок не влияет, repeat-safe.

Честное поведение: движок не сетаплен → вкладка покажет 503 с подсказкой (теми
же пунктами 3–5), НЕ молчанием и НЕ фейковыми цифрами.

## 7. MCP-сервер (для OpenCode/клиентов MCP)

```bat
cd /d C:\poe2-kit
node apps\mcp\dist\index.js --smoke
```

Должно вывести `Registered tools: 76`. Подключение в конфиг MCP-клиента —
`node C:\poe2-kit\apps\mcp\dist\index.js` (stdio). Живой оракул доступен тулам
`poe2_recompute` (в т.ч. `scenarios=[...]` — что-если-матрица до 12 сценариев),
`poe2_build_estimate` (option `goals` — дерево целей по уровням).

## 8. Оверлей (по желанию)

```bat
cd /d C:\poe2-kit\apps\overlay
npm start
```

Не зависит от оракула; PoB-функции — через web-вкладку или MCP.

## Что НЕ должно пугать

- «Новая запись в логах luajit: движок отработал one-shot и завершился» —
  это норма для тула `poe2_recompute`;
- Статус сессии «stopped» на вкладке до первой загрузки билда — сессия
  поднимается лениво, это экономия 2.5 с boot'а;
- Расхождение цифр с настольным PoB2 того же тега v0.23.1 — невозможно по
  построению (тот же движок); если видно — проверь, что скачивал именно релиз,
  а не dev-ветку.

## Сверка пинов (для скептиков)

`oracle\PINNED.md`: тег движка v0.23.1, SHA256 бинарей LuaJIT, контракт 4.
Кросс-платформенный селфтест живого стека:

```bat
cd /d C:\poe2-kit
node oracle\headless-selftest.mjs C:\TestPE\PathOfBuilding-PoE2\src
```

Ожидание: `[selftest] OK: contract 4, ping/new_build/whatif(3)/CAS — всё зелёное`.
