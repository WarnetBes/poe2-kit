# Офлайн-датасеты PoE2 Kit

Данные Path of Exile 2, извлечённые из файлов игры (`.datc64`) проектом
**hivemind-poe2-mcp** (патч 0.5 «Return of the Ancients», ревизия 12,
`2026-06-01`). Скопированы в poe2-kit с разрешения владельца репозитория.

## Состав

| Путь | Что содержит | Размер |
|---|---|---|
| `version.json` | Версия патча и ревизия данных | 5 КБ |
| `ascendancies/ascendancies.json` | Асценданси-классы (все 23 активных) | 6 КБ |
| `skill_gems/skill_gems_v2.json` | Активные гемы: cost/статы по уровням | 10 МБ |
| `passive_tree/tree.json` | Дерево пассивок: ~9605 узлов | 5 МБ |
| `base_items.json` | Базовые предметы (~5382) + классы | 1.5 МБ |
| `stats.json` | Внутренние stat_id (~27k) | 2 МБ |

Оригинальный источник: `data/game/` в hivemind-poe2-mcp (экстракторы
`scripts/extract_*_v2.py`). Формат данных — свойства игры Grinding Gear Games,
приведённые сообществом; использование — как и у RePoE (fair use, некоммерческий
инструментарий сообщества).

## Обновление

Заменить файлы более новой ревизией из hivemind-poe2-mcp (или прогнать их
экстракторы) и обновить `version.json`. Загрузчики в
`packages/core/src/dataset.ts` версионно-независимы (поля совместимы).
